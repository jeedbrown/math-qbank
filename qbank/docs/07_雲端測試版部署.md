# 07 雲端測試版部署（Cloudflare Workers ＋ D1）

目標：把本模組放到一個**測試用子網域**，讓教師在瀏覽器操作，不需在自己電腦裝 Node。
仍然不接付費 API；原題資料存於 Cloudflare D1（私有），整站以帳號密碼保護，並禁止搜尋引擎索引。

## 一、架構

| 元件 | 內容 |
|---|---|
| `qbank/worker.js` | Worker 入口：Basic 登入檢查 → `/api/*` 交給 `lib/api.js`（與本機版共用）→ 其餘路徑由 `ASSETS` 提供 `ui/` |
| `qbank/lib/dbx.js` | 資料庫轉接層：本機 node:sqlite／雲端 D1 同一套程式 |
| `qbank/wrangler.jsonc` | 獨立 Worker 設定（名稱 `qbank-test`），與本 repo 根目錄的正式 Worker、資料庫完全分開 |
| 密鑰 `QBANK_AUTH` | 「帳號:密碼」。**未設定時整站回 503**，不會裸奔 |

與本機版的差異：D1 沒有互動式交易，匯入等多列寫入是逐列執行；中途失敗時已寫入的列會保留，重新匯入會被視為「不變」而不重複，不會產生壞資料。

## 二、部署步驟（在擁有該網域 Cloudflare 帳號的電腦上執行）

前提：Node 22＋、`npx wrangler login` 已登入**該網域所在的 Cloudflare 帳號**；網域已在該帳號託管 DNS。

### 方法 A：一鍵腳本（建議）

```bash
git fetch origin qbank-module && git checkout qbank-module
bash qbank/scripts/deploy.sh <測試子網域>      # 例：bash qbank/scripts/deploy.sh test.example.com
```
腳本會：建立 D1（已存在則查 id）並寫進 `wrangler.jsonc` → 沒有密鑰就要求輸入 `QBANK_AUTH`（帳號:密碼，**只用英數與符號**，Basic 驗證不支援中文）→ `wrangler deploy --domains <子網域>`（Cloudflare 自動建 DNS 與憑證）。

### 方法 B：手動

```bash
cd <repo>/qbank
npx wrangler d1 create qbank-test           # 把回傳的 database_id 填進 wrangler.jsonc
npx wrangler secret put QBANK_AUTH          # 帳號:密碼
npx wrangler deploy --domains <測試子網域>   # 或不帶 --domains，之後到後台 Domains & Routes 加
```

### 方法 C：不用本機指令，走 Cloudflare 後台的 Git 連結

Workers & Pages → Create → Import a repository → 選本 repo、分支 `qbank-module`、Root directory `qbank`、Build command 留空、Deploy command `npx wrangler deploy` → 建立後到 Settings：Bindings 加 D1（qbank-test，變數名 `DB`）、Variables and Secrets 加密鑰 `QBANK_AUTH`、Domains & Routes 加子網域。之後每次推送該分支會自動重新部署。限制：該 Cloudflare 帳號必須同時擁有網域與 GitHub 連結權限。

部署後檢查（必做）：
1. 無帳密開啟網址 → 要求登入（401）；錯誤密碼 → 仍 401。
2. 登入後首頁顯示「題庫總覽」，資料庫標示「Cloudflare D1：qbank-test」。
3. `/robots.txt` 內容為 `Disallow: /`，回應標頭含 `X-Robots-Tag: noindex`。
4. 匯入範例 `samples/sample_questions.csv` → 總題數 8；再匯入一次 → 不變 8。
5. 批次 AI 分析 → 產生指令 → 貼回一筆結果 → 待審核 → 接受。
6. 匯出已確認分析 CSV 可下載。

## 三、本機模擬（不需帳號）

```bash
cd qbank && printf 'QBANK_AUTH=teacher:test-pass\n' > .dev.vars     # .dev.vars 不進版控
npx wrangler dev --config wrangler.jsonc --local --port 8791
# 瀏覽器開 http://127.0.0.1:8791/ ，帳號 teacher 密碼 test-pass
```
本地 D1 資料存在 `.wrangler/state/`（已被 .gitignore 排除）。

## 四、資料與權限注意

- 原題為出版社資料：D1 內容、匯出檔、密碼都不得貼到公開位置；測試網址只給教師。
- 此為單一共用帳密的測試版，沒有角色區分與操作者身分；正式整合時應改接正式後台登入。
- 要換密碼：`npx wrangler secret put QBANK_AUTH` 重新輸入即可。
- 要清空測試資料：`npx wrangler d1 execute qbank-test --remote --command "DELETE FROM analyses; DELETE FROM review_log; ..."`，或刪掉 D1 重建。
- 正式題庫寫回仍未啟用；雲端版只是把本機版搬到瀏覽器可用的位置。
