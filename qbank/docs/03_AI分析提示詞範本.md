# 03 AI 分析提示詞範本

由 `lib/prompts.js` 自動產生（`node qbank/cli.js prompt` / `variant-prompt`，或介面「批次 AI 分析」「類題工作區」）。下面是用虛構示範題產生的實際輸出，供教師了解格式；正式使用時請以模組產生的版本為準（會隨規準版本更新）。

使用方式：複製整段 → 貼到現有 AI 訂閱服務（ChatGPT、Claude 等）→ 只把回傳的 JSON 貼回模組。AI 若在 JSON 前後加了說明文字，請只貼 JSON 部分。每批題數與字數可調（預設 8 題／6,000 字題目文字；固定說明與代碼表約 5,000 字）。

## 二、類題產生指令（1 題示範，選項：保留概念＋換數字＋換情境）

```text

【操作要求】
- 保留原題核心概念（必選）
- 更換數字
- 更換生活情境
- 每題產生 2 個類題。

【硬性規則】
1. question_id、question_version 原樣照抄。
2. 類題必須保留原題的數學概念與解題結構，不能只是改人名；也不能因改數字造成無解、矛盾、不合理（例如人數不是整數、負數長度）。
3. 答案必須與題目一致；請附完整解題步驟、其他解法、驗算方式與教師教學提示。
4. 可用算式獨立驗算的題目，請在 check 填 type: arithmetic，expression 只用數字與 + - * / ( ) ^，expected 填算式結果；圖形題、情境判斷題、開放題填 type: none。
