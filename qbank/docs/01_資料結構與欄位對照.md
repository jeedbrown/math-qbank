## 一、原始題庫 21 欄（全部保留，不改名、不改順序、不改內容）

| # | 欄名 | 用途 | 身分鍵 | 內容指紋 |
|---|---|---|---|---|

| 2 | 年級 | 原始年級標示（中年級／高年級） | | ✔ |
| 3 | 套別 | 套別 | ✔ | |
| 4 | 週次 | 週次 | | ✔ |
| 5 | 題號 | 套內題號 | ✔ | |
| 6 | 對應課程 | 出版社冊別與單元（管理介面稱「課堂單元」） | | ✔ |
| 7 | 主題 | 題目主題 | | ✔ |
| 8 | 題目 | 原題全文（含換行） | | ✔ |

| 13 | 影片來源 | | | |
| 14–18 | 影片1～影片5 | 試算表為 HYPERLINK 公式，CSV 只留顯示文字（▶ 影片／▶ A…） | | |
| 19 | 題目PDF | 同上，CSV 只留「開啟PDF」 | | |
| 20 | PDF頁碼 | | | |
| 21 | 備註 | 含圖／符號提示 | | ✔ |

- **身分鍵**＝`題庫來源|套別|題號`（正規化空白後）。盤點 437 題此組合唯一；列號、週次不參與，所以排序、插列、刪列不改變 ID。
- **題目 ID**＝`Q` + SHA-256(`qbank-identity|身分鍵`) 前 12 碼大寫，例 `Q0D6F79C95550`。永久不變。
- **內容指紋**＝上表打 ✔ 的欄位正規化後的 SHA-256。指紋相同→「不變」略過；不同→新版本（舊版本保留，教師已確認結果不被覆蓋，只標示「可能失效」）。影片／PDF 連結文字變動不產生新版本。
- 若來源檔多出非 21 欄的欄位，會以 `_extra:欄名` 一併存進 `raw_json`，不丟失也不混入正式欄位。
- Google Drive 匯出的列索引不是第 22 欄；本模組不讀列索引。

## 四、類題結果欄位（`variants`）

AI 回傳：`{question_id, question_version, variants:[{text, answer, solution_steps[], alt_solutions[], verification, teaching_tips, check:{type: arithmetic|none, expression, expected}}]}`。
`check.expression` 只允許數字與 `+ - * / ^ ( )`，由模組獨立計算並與 `expected` 及答案中的數值比對；不符→ auto_failed；無算式→ unverified。**auto_passed 不等於教師確認**。

## 五、匯出格式

| 匯出 | 內容 |
|---|---|
| confirmed / pending | 每題一列，含題目識別＋分析欄位（中文欄名），技能分「正式」與「建議，未核准」兩欄，迷思概念標 [預測性]／[已觀察] |
| anomalies | 題目品質旗標、分析可能失效、詞彙建議、類題驗算失敗 |
| links | 題目與課程關聯 |
| questions | 題目 ID＋版本＋原始 21 欄（可作為日後寫回對照） |
| backup | 全部資料表 JSON |
